Add `react-web3-icons/manifest`: a machine-readable catalog of every icon export (`name`, `category`, `chainId`/`slug`/`ticker` identifiers, `deprecated` flag), plus a plain-JSON variant at `react-web3-icons/manifest.json`. Useful for building icon pickers, search indexes, and docs without importing the component bundles. The manifest is auto-generated and guarded by a sync test.
